El enrutamiento del sistema se basa en un **Controlador Frontal** ([index.php](file:///c:/xampp/htdocs/TIENDA_MVC/index.php)) que canaliza todas las peticiones a través de reglas de reescritura.

## Enrutamiento en `.htaccess`

El archivo `.htaccess` redirige de forma transparente las peticiones hacia el parámetro `route` de `index.php` siempre que no correspondan a un archivo físico (`-f`) o carpeta física (`-d`):

```apache
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php?route=$1 [QSA,L]
```

## Estructura del Enrutador

El flujo de control se resuelve mediante un bloque `switch` en el archivo raíz del proyecto:

```php index.php
$route = $_GET['route'] ?? 'catalogo';

switch ($route) {
    case 'login':
        $authController->showLogin();
        break;
    case 'auth/login':
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            $authController->login();
        }
        break;
    // ... otros casos de uso
    case 'catalogo':
    default:
        $publicController->catalogo();
        break;
}
```
