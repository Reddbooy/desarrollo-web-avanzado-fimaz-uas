## Requisitos Previos

Antes de comenzar, asegúrate de tener instalado:

* **Servidor Local**: [XAMPP](https://www.apachefriends.org/), WAMP o un entorno similar con **PHP 8.0 o superior** y **MySQL/MariaDB**.
* **Apache mod_rewrite**: El módulo de reescritura de Apache debe estar activo para permitir el enrutamiento amigable definido en `.htaccess`.

---

## Pasos para la Instalación

<Steps>
  <Step title="Ubicar el Proyecto">
    Copia o clona el directorio del proyecto dentro del directorio raíz de tu servidor web (en XAMPP suele ser `C:\xampp\htdocs\TIENDA_MVC`).
  </Step>
  <Step title="Preparar la Base de Datos">
    1. Abre tu administrador de base de datos (por ejemplo, phpMyAdmin).
    2. Crea una base de datos llamada `tienda_mvc`.
    3. Importa el archivo `tiendamvc.sql` ubicado en la raíz del proyecto para generar las tablas `productos` y `usuarios` con datos iniciales.
  </Step>
  <Step title="Configurar la Conexión de Base de Datos">
    Abre el archivo [config/Database.php](file:///c:/xampp/htdocs/TIENDA_MVC/config/Database.php) y configura los parámetros de conexión con tus credenciales de base de datos locales:

    ```php config/Database.php
    private string $host = "localhost"; // O la dirección de tu servidor de BD
    private string $dbname = "tienda_mvc";
    private string $username = "tu_usuario";
    private string $password = "tu_contraseña";
    ```
  </Step>
  <Step title="Iniciar la Aplicación">
    Inicia los módulos **Apache** y **MySQL** en tu panel de control de XAMPP. Luego, abre tu navegador y accede a:
    
    ```http
    http://localhost/TIENDA_MVC/
    ```

    *Nota: Si prefieres usar el servidor de desarrollo integrado de PHP, puedes ejecutar el siguiente comando desde la raíz del proyecto:*
    
    ```bash
    php -S localhost:8080
    ```
    *E ingresa a `http://localhost:8080`.*
  </Step>
</Steps>

## Credenciales de Acceso

Para acceder al panel administrativo y realizar operaciones de creación, edición o eliminación de productos, puedes iniciar sesión en la sección **Administrador** (`/login`):

* **Usuario**: `admin`
* **Contraseña**: `admin123`
