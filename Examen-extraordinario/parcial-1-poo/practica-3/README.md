# Práctica 3 - Manejo de Excepciones en PHP

## Descripción del Sistema

valida el formato del correo electrónico y lanza excepciones cuando el dato es incorrecto.


## Validación

La clase Usuario valida el correo con filter_var():

El código usa try/catch para capturar errores sin detener el programa.



## Ejecutar
 Abre: http://localhost/



## Conceptos POO

- Herencia con extends
- Validación de datos  
- Manejo de errores con try/catch 
- Encapsulamiento
