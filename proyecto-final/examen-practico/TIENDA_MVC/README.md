PROYECTO FINAL: TIENDA MVC UPDATES

Requisitos:
- PHP 8 o superior
- MYSQL / MariaDB
- Apache (XAMPP recomendado)

Pasos de instalacion
1. Copiar la carpeta "TIENDA_MVC" dentro de htdocs.
2. Abrir phpMyAdmin.
3. Importar el archivo database.sql.
4. Verificar en config/Database.php que usuario y contraseña sean correctos.
5. Abrir en navegador:
