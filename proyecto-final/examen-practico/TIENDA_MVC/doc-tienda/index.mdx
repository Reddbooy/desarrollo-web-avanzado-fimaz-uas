Bienvenido a la documentación de **Tienda MVC**. Este proyecto está diseñado para la administración de un catálogo de productos con un panel administrativo seguro, paginación dinámica, validaciones contra vulnerabilidades comunes (como ataques CSRF) y un diseño responsivo utilizando Bootstrap 5.

## Características Principales

* **Patrón MVC**: Separación clara de la lógica de negocio (Modelos), la lógica de presentación (Vistas) y el flujo de control (Controladores).
* **Base de Datos con PDO**: Conexiones seguras a MySQL/MariaDB empleando sentencias preparadas y control de excepciones (`Try-Catch`).
* **Transacciones de BD**: Integridad de datos garantizada en procesos críticos (creación, edición y eliminación de productos) mediante confirmaciones (`commit`) y reversiones (`rollback`).
* **Seguridad Incorporada**:
  * Autenticación con contraseñas encriptadas mediante `bcrypt` (`password_hash`).
  * Validación estricta de tokens CSRF en todos los envíos POST.
  * Control de acceso en rutas administrativas mediante variables de sesión.
* **Interfaz Responsiva**: Diseñada con Bootstrap 5 para garantizar una excelente experiencia de usuario tanto en dispositivos móviles como de escritorio.
