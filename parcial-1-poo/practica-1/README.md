# Práctica: Clase Usuario en PHP

## Objetivo

Crear una clase Usuario en PHP aplicando encapsulamiento con atributos privados y métodos.

## Descripción

- Clase Usuario con: Atributos privados( nombre y correo).
- Constructor.
- Métodos.

## Archivos

- Usuario.php 
- index.php 


## Ejemplo de uso

```php
$usuario = new Usuario("Eduardo Rojas", "eduardogarroj04@gmail.com");
echo $usuario->getNombre();  
echo $usuario->getCorreo();  

```
